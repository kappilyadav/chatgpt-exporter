# Chrome Web Store: translated listings (copy-paste kit, not shipped in the zip)

The extension itself speaks 35 languages (the 34 the Web Store offers, plus Hindi). The Web Store listing is separate: each language has its own title, summary and description, and you add them in the Developer Dashboard.

## How to add a language
1. Developer Dashboard > your item > **Store listing**.
2. Use the **Language** dropdown at the top (or **Add language**) and pick the language.
3. Paste the **Title**, **Summary** and **Description** from the matching section below. Title and summary are the same strings that are inside the package (`_locales/<code>/messages.json`), so they always match the extension.
4. Optional: upload screenshots for that language. The screenshots in `store-assets/out` are English; reuse them if you do not have translated ones.
5. Save the draft, repeat for the other languages, then **Submit for review** once.

Language code for the package folder is shown in brackets. Norwegian is `no` in the package, with `nb` shipped as a copy because Chrome reports Norwegian Bokmål as `nb`.

Keep the text as written: it follows the Store's rules (natural sentences, the formats named once, no keyword lists). Every description is about 600 to 900 characters; the limit is 16,000.

Limits: title 75 characters, summary 132 characters (all checked by `python3 scripts/build_locales.py`).
